class MedianFinder:

    def __init__(self):
        self.max1 = [] # 最大堆
        self.min2 = [] # 最小堆

    def addNum(self, num: int) -> None:
        if len(self.max1) == len(self.min2):
            heappush(self.max1, -heappushpop(self.min2, num))
        else:
            heappush(self.min2, -heappushpop(self.max1, -num))

    def findMedian(self) -> float:
        if len(self.max1) == len(self.min2):
            return (-self.max1[0] + self.min2[0]) / 2
        else:
            return -self.max1[0]

**大小堆：**
中位数可以将数值集合划分为相等的两部分（还记得 `max1` 和 `min2` 吗）
因此在 `addNum` 不断添加数字的情况下，我们要维护：
1. `max1` 和 `min2` 的大小尽量相等。规定：在有奇数个数时，`max1` 比 `min2` 多一个数
2. 保证 `max1` 的所有元素都小于等于 `min2` 的所有元素

因此，在加入元素时**分类讨论**：
- 如果当前 `max1` 和 `min2` 的大小相等：
	- 如果添加的数字比较大，需要添加到 `min2` 中后，再把 `min2` 的最小值从中去掉加入 `max1` 中
	- 如果添加的数字比较小，添加到 `max1` 中
	- 以上步骤可以**合并**为先把数字添加到 `min2` 中，然后把 `min2` 的最小值从中去掉，加入 `max1` 中
- 如果当前 `max1` 比 `min2` 多一个数：
	- 如果添加的数字比较大，添加到 `min2` 中
	- 如果添加的数字比较小，需要添加到 `max1` 中后，再把 `max1` 的最大值从中去掉加入 `min2` 中
	- 以上步骤可以**合并**为先把数字添加到 `max1` 中，然后把 `max1` 的最大值从中去掉，加入 `min2` 中

`heapq.heappush(heap, x)`：把元素 `x` 插入到**最小堆** `heap` 里，并保持堆性质（堆顶永远是最小值）
注意：在 `max1` 中，元素是以负数形式储存的。因为 python 中没有最大堆，保持 `max1[0]` 是最小值相当于保持 `-max1[0]` 是最大值，转换最小堆为最大堆
