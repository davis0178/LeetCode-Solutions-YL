```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        ans = 0
        min_price = prices[0]
        for p in prices:
            ans = max(ans, p - min_price)
            min_price = min(min_price, p)
        return ans
```

从左到右枚举价格 `p`，想要获得最大利润，需要在价格最低那天买入
可以用 `min_price` 维护价格的最小值。先更新答案，再更新 `min_price`，以保证 `min_price` 在 `p` 之前。
