```python
class Solution:
    def partition(self, nums: List[int], left: int, right: int) -> int:
	    """
	    [left, right] 规定子数组，其中选择 pivot
	    返回 pivot 在重新排列之后在 nums 中的下标
	    如果子数组所有元素都等于 pivot，返回子数组的中心下标，防止退化
	    """
        i = randint(left, right) # 随机选择基准元素
        pivot = nums[i]
        nums[i], nums[left] = nums[left], nums[i] # pivot 与子数组第一个元素交换

        i, j = left + 1, right # 双指针遍历（排除了 pivot）
        while True:
	        # 对了不用管（两个条件都没有带等于，这样等于也会被交换，防止退化）
            while i <= j and nums[i] < pivot:
                i += 1
            while i <= j and nums[j] > pivot:
                j -= 1
            if i >= j:
                break
			
			# 不对就交换
            nums[i], nums[j] = nums[j], nums[i]
            i += 1
            j -= 1
		
		# 完事，把 pivot 与 j 交换（因为 i 可能越界）        
        nums[left], nums[j] = nums[j], nums[left]
        return j # 返回 pivot 的下标

    def findKthLargest(self, nums: List[int], k: int) -> int:
        n = len(nums)
        target_index = n - k # 需要找的 index
        left, right = 0, n - 1 # 闭区间
        while True:
            i = self.partition(nums, left, right) # 子数组中随机选择 pivot，返回排列后的下标
            if i == target_index: # 正好找到了
                return nums[i]
            if i > target_index: # 大于在左找
                right = i - 1
            else: # 小于在右找
                left = i + 1
``` 
**快速选择**：
第 $k$ 大元素在升序数组中的下标是 $n - k$
1. 在 `nums` 中==随机选择==一个基准元素 `pivot`
2. 把小于等于 `pivot` 的元素放在 `pivot` 左侧，把大于等于 `pivot` 的元素放在 `pivot` 右侧。这种粗略排序 `nums` 的方式让 `pivot` 的位置就是在**升序数组中的位置**
3. 设 `pivot` 在 `nums` 中的下标为 $i$
	- 如果 $i = n - k$，那么答案正好就是 `pivot`
	- 如果 $i > n - k$，那么答案在 `pivot` 左侧，在左侧数组中寻找，重复第一步
	- 如果 $i < n - k$，那么答案在 `pivot` 右侧，在右侧数组中寻找，重复第一步

 这类似二分查找，每次能够把问题规模缩小一半，就可以用 `O(n)` 时间解决

为什么划分数组条件都是小于等于？因为如果数组包含大量重复元素，算法可能退化至 `O(n^2)` 。特别地，如果子数组所有元素都相同，要返回子数组的中心下标，避免退化
