题意是在两个有序数组中查找第 $k = \frac{m + n}{2}$ 小的数（如果 $m + n$ 是奇数，返回第 $k$ 小的数，如果 $m + n$ 是偶数，返回第 $k$ 小和第 $k + 1$ 小的数的平均值）
那么，可以把两个正序数组均匀分为两组，其中第一组的元素都小于第二组，然后根据**第一组的最大值和第二组的最小值**考虑答案

```python
class Solution:
    def findMedianSortedArrays(self, nums1: List[int], nums2: List[int]) -> float:
        if len(nums1) > len(nums2):
            nums1, nums2 = nums2, nums1
        
        m, n = len(nums1), len(nums2)
        nums1 = [-inf] + nums1 + [inf]
        nums2 = [-inf] + nums2 + [inf]

        i, j = 0, (m + n + 1) // 2
        while True:
            if nums1[i] <= nums2[j + 1] and nums1[i + 1] > nums2[j]:
                max1 = max(nums1[i], nums2[j])
                min2 = min(nums1[i + 1], nums2[j + 1])
                return max1 if (m + n) % 2 else (max1 + min2) / 2
            i += 1
            j -= 1
```
设 `nums1` 有 `i` 个数在第一组，`nums2` 有 `j` 个数在第一组（一开始 `nums1` 都是红色的，之后每次从 `nums1` 最后拿走一个红色填补到 `nums2` 开头，其余都是蓝色的）。那么，`i` 每增加 1，`j` 就减少 1，且初始化 `i = 0` 时 `j = (m + n + 1) // 2`（第一组和第二组长度相等）。那么，`j = (m + n + 1) // 2 - i`。
**枚举法**就是找到那一个唯一的划分法（此时 `nums1[i] <= nums2[j + 1] and nums1[i + 1] > nums2[j]`，双重保证，保证第一组最大值小于等于第二组的最小值），维护 `max1` 和 `min2` 最后更新答案。
**为什么要垫上正负无穷**：为了方便处理 `i = -1` 和 `i + 1 = m`，即 `nums1` 有 0 个数在第一组的情况和 `nums1` 有 m 个数在第一组的情况，保证下标不越界
**为什么要保证 $m \le n$**：保证 `j = (m + n + 1) // 2 - i` 在 `nums2` 中一定取得到

我们可以选择二分做法来优化：
