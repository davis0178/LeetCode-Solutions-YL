```python
class Solution:
    def minPathSum(self, grid: List[List[int]]) -> int:
        @cache
        def dfs(i: int, j: int) -> int:
            if i == 0 and j == 0:
                return grid[0][0]
            if i < 0 or j < 0:
                return inf
            return min(dfs(i - 1, j), dfs(i, j - 1)) + grid[i][j]
        
        m, n = len(grid), len(grid[0])
        return dfs(m - 1, n - 1)
```

把大问题变为小问题：最后一格只能是由左格或上格走到。从左格走过来，则可以缩小成去除最后一列的子问题。从上格走过来，则可以缩小成去除最后一行的子问题。如果是从左边过来，那么必须先到达 $(i,j−1)$，我们需要知道从左上角到 $(i,j−1)$ 的最小价值和，再加上 $grid[i][j]$，得到 $dfs(i,j−1)+grid[i][j]$。如果是从上边过来，那么必须先到达 $(i−1,j)$，我们需要知道从左上角到 $(i−1,j)$ 的最小价值和，再加上 $grid[i][j]$，得到 $dfs(i−1,j)+grid[i][j]$

因此，得到状态转移方程：$$dfs(i,j)=min(dfs(i,j−1),dfs(i−1,j))+grid[i][j]$$
