```python
class Solution:
    def isValid(self, s: str) -> bool:
        # 长度得是偶数，不然一定不有效
        if len(s) % 2:
            return False
        
        mp = {')': '(', ']': '[', '}': '{'}
        st = []
        for x in s:
            if x not in mp: # 左括号
                st.append(x)
            elif not st or st.pop() != mp[x]: # 没有对应左括号或不对应
                    return False
        return not st
```
**邻项消除**问题：不断消除相邻的匹配括号，如果可以把 s 变为空字符串，就是有效字符串
创建 mapping `mp` 的作用是区分左右括号，且找到与右括号成对的左括号。从左到右遍历 s，如果是左括号，入栈。如果是右括号，它必须和**栈顶的对应左括号**组成一对，消除弹出栈顶
遍历结束，栈空才说明匹配
