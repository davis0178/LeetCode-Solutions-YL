```python
class Solution:
    def jump(self, nums: List[int]) -> int:
        ans = 0
        cur_right = 0 # 已经建造的桥的右端点
        next_right = 0 # 下一座桥的右端点的最大值
        for i in range(len(nums) - 1):
            next_right = max(next_right, i + nums[i]) # 可能性
            if i == cur_right: # 无路可走时
                cur_right = next_right
                ans += 1
        return ans
```

维护已经建造的桥的右端点和下一座桥的右端点的**最大值**。当发现无路可走时，必须建桥。这里并不是在无路可走的那个位置建桥，而是可以将时光倒流到能够跳到最远点的那个位置建桥（可能性）。“在无路可走之前，我们只是在默默地收集信息”。这样就能选择右端点最大的桥，它会让你走得更远。（一切不一定都是最好的安排，学习计算机就是要能够回到过去，达到全局最优）
代码只需要遍历到 `n - 2`，因为 `n - 1` 已经是终点了，到达 `n - 2` 时要么已经能够到达终点，要么还需要建造最后一座桥。(如果遍历到 `n - 1`，可能多造一座桥)
