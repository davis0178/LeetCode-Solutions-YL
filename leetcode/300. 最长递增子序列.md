```python
class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        @cache
        def dfs(i: int) -> int:
            res = 0
            for j in range(i):
                if nums[j] < nums[i]:
                    res = max(res, dfs(j))
            return res + 1
        return max(dfs(i) for i in range(len(nums)))
```
`dfs(i)` 表示以 `nums[i]` **结尾**的最长递增子序列的长度
枚举子序列的倒数第二个数的下标是 `j`，如果 `nums[j] < nums[i]`，那么有 $$dfs(i) = dfs(j) + 1$$取最大值。
要考虑所有结尾的位置，因为以最后一个元素结尾未必能够形成最长的递增子序列
