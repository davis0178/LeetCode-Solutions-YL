```python
class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        max_len = max(map(len, wordDict)) # 限制下面 j 的循环次数
        words = set(wordDict)

        @cache
        def dfs(i: int) -> bool:
            if i == 0: # 成功拆分
                return True
            
            for j in range(i - 1, max(-1, i - max_len - 1), -1):
                if s[j: i] in words and dfs(j):
                    return True
            
            return False
        
        return dfs(len(s))
```
原问题**等价**：把 `s` 划分成若干段，使得每段都在 `wordDict` 中
枚举 leetcode 的最后一段长度：
`leetcod` `e` -> 能否把 `leetcod` 划分成若干段，使得每段都在 `wordDict` 中？
`leetco` `de` -> 能否把 `leetco` 划分成若干段，使得每段都在 `wordDict` 中？
`leetc` `ode` -> 能否把 `leetc` 划分成若干段，使得每段都在 `wordDict` 中？
这些问题都可以拆分成**和原问题相似的、规模更小的子问题**，因此可以用**递归解决**

定义状态为 $dfs(i)$，表示能否把前缀 `s[:i]` 划分为若干段，使得每段都在 `wordDict` 中。设 `wordDict` 中字符串的最长长度为 $maxLen$，枚举的上限不超过 $maxLen$。枚举 $j = i - 1, i - 2, i - 3,..., max(i - maxLen, 0)$，**只要其中一个 `j` 满足** `s[j:i]` 在 `wordDict` 中且 `dfs(j) = True`，那么 `dfs(i)` 就是 `True`
