```python
class Solution:
    def longestValidParentheses(self, s: str) -> int:
        stk = [-1] # 红线
        ans = 0
        for i, ch in enumerate(s):
            if ch == '(': # 炸弹
                stk.append(i) # 记录炸弹
            elif len(stk) > 1: # 栈顶是炸弹（而不是红线）
                stk.pop() # CT 阵营获胜
                ans = max(ans, i - stk[-1]) # 右端点为 i 时，左端点最小是 stk[-1] + 1
            else: # 栈顶是红线
                stk[0] = i # 替换栈底
        return ans
```

**O(n) 拆炸弹：**
有效括号 => 每次消除一对相邻的左括号和右括号，**不断消除**。如果最终变成空串，则消除之前是有效括号。值得注意的是，两个有效括号可以**拼成一个更长的有效括号**

思路：
为了记录下标、拆除最近炸弹，我们需要一个**后进先出的数据结构——栈**
一开始把**虚拟红线**的下标 -1 入栈。在任何时候，栈的结构都是：
- 栈底是红线的下标
- 其余是未被拆除的炸弹下标
从左到右遍历 $s$，分类讨论：
- 如果 $s[i]$ 是左括号（炸弹），那么把其下标 $i$ 入栈
- 如果 $s[i]$ 是右括号（拆弹器）：
	- 如果栈中至少有两个数，那么拆单，弹出栈顶。新的栈顶 $j$ 就是未被拆除的炸弹（或者红线）的下标。下标区间 $[j+1,i]$ 是合法子串，用其长度 $i - j$ 更新答案的最大值。
	- 如果栈中只有一个数（红线），那么后续合法子串不能包含 $s[i]$，所以 $i$ 变成新的红线下标，替换栈底

2026.3.2 不是炸弹才能拆弹。所以中间是 `elif`。拆完弹之后，被拆掉炸弹后剩下的 `stk[-1]` 就是**合法位置前一个位置**
