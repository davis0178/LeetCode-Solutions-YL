```python
class Solution:
    def generate(self, numRows: int) -> List[List[int]]:
        c = [[1] * (i + 1) for i in range(numRows)] # 行号为 i 的行有 i + 1 个元素
        for i in range(2, numRows): # 从第二行开始递推
            for j in range(1, i): # 除去第一个元素和最后一个元素
                c[i][j] = c[i - 1][j - 1] + c[i - 1][j]
        return c
```
将杨辉三角每一排左对齐，发现两个规律：
- 每一排的第一个数和最后一个数都是 1
- 其余数字，遵循 $c[i][j] = c[i - 1][j - 1] + c[i - 1][j]$
