```python
class Solution:
    def maxProduct(self, nums: List[int]) -> int:
        n = len(nums)
        f_max = [0] * n
        f_min = [0] * n
        f_max[0] = f_min[0] = nums[0] # 一开始最大最小都是 nums[0]
        for i in range(1, n): # 开始更新
            x = nums[i] # 拿到新元素
            # 拼或不拼，拼就把和最大最小的乘积都算一下
            f_max[i] = max(f_max[i - 1] * x, f_min[i - 1] * x, x)
            f_min[i] = min(f_max[i - 1] * x, f_min[i - 1] * x, x)
        return max(f_max)
```

遍历 `nums` 的同时，维护两个信息：
- 右端点下标为 `i` 的子数组的**最大乘积**，记作 $f_{max}[i]$
- 右端点下标为 `i` 的子数组的**最小乘积**，记作 $f_{min}[i]$
设 $x = nums[i]$，分类讨论：
- $x$ **单独**组成一个子数组，那么 $f_{max}[i] = x$
- $x$ 和前面的子数组**拼起来**，$x$ 为正，拼 $f_{max}[i - 1]$，$x$ 为负，拼 $f_{min}[i - 1]$
三种情况都算一下，取最大值，这样就无需判断 $x$ 是正是负了
