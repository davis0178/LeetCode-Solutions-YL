```python
@cache
def dfs(i: int, j: int) -> int: # 前 i 个完全平方数中选一些数，满足元素和恰好等于 j
    if i == 0:
        return inf if j else 0
    if i * i > j: # 选不鸟
        return dfs(i - 1, j)
    return min(dfs(i - 1, j), dfs(i, j - i * i) + 1) # 选或不选取最小值

class Solution:
    def numSquares(self, n: int) -> int:
        return dfs(isqrt(n), n) # 从根号 n 开始找
```
**完全背包问题：记忆化搜索**
把完全平方数（$1, 4, 9, 16$）视作物品**体积**，物品**价值**都是 1
由于每个数（物品）选的次数没有限制，这道题是一道**标准的完全背包问题**（可以重复选）
取最小值，相当于把 n 分解成最少的完全平方数之和

`isqrt` 返回 x 的平方根，并将平方根数向下舍入到最接近的整数

注意这里 `i == 0` 就可以直接退出 dfs 了。dfs 不写在外面会超时
