```python
class Solution:
    def search(self, nums: List[int], target: int) -> int:
        left, right = -1, len(nums) - 1
        while left + 1 < right:
            mid = (left + right) // 2
            x = nums[mid]
            if target > nums[-1] >= x:
                right = mid
            elif x > nums[-1] >= target:
                left = mid
            elif x >= target:
                right = mid
            else:
                left = mid
        return right if nums[right] == target else -1
```
旋转将 `nums` 分为两个递增段，第一段数整体大于第二段
二分取到的数 `x = nums[mid]` 和 `target` 在两个递增段上共有四种（$2 * 2 = 4$）位置关系：
1. x 和 target 在不同的递增段：
	- target 在第一段，x 在第二段，说明 target 在 x 左边
	- target 在第二段，x 在第一段，说明 target 在 x 右边
2. x 和 target 在相同的递增段：直接使用 lower_bound 函数
所以旋转二分相当于在普通二分上多加了两个条件
