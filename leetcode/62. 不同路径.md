```python
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        @cache
        def dfs(i: int, j: int) -> int:
            if i < 0 or j < 0: # 递归边界：无路可走
                return 0
            if i == 0 and j == 0: # 递归边界：起点自己算一条路径
                return 1
            return dfs(i - 1, j) + dfs(i, j - 1)
        return dfs(m - 1, n - 1)
```
**递归搜索 + 保存递归返回值 = 记忆化搜索**
最后一步可以缩小成“从起点 $(0, 0)$ 走到 $(m - 2, n - 1)$ 的路径数” + “从起点 $(0, 0)$ 走到 $(m - 1, n - 2)$ 的路径数”
这些问题都是和原问题相似的、规模更小的子问题，可以用递归解决。也就是 $$dfs(i, j) = dfs(i - 1, j) + dfs(i,j - 1)$$
```python
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        f = [[0] * (n + 1) for _ in range(m + 1)]
        f[0][1] = 1
        for i in range(m):
            for j in range(n):
                f[i + 1][j + 1] = f[i][j + 1] + f[i + 1][j]
        return f[m][n]
```
**1:1 翻译成递推**
$f[i + 1][j + 1]$ 就相当于 $dfs(i, j)$。为什么要 +1 是因为可以把 $f[0][j]$ 和 $f[i][0]$ 作为初始值。相应递推式：$$f[i+1][j+1]=f[i][j+1]+f[i+1][j]$$初始值：
- $f[0][j] = f[i][0] = 0$
- $f[1][1] = 1$
也可以把 $f[0][1]$ 初始化为 1，这样就无需单独计算 $f[1][1]$。从 $dfs$ 角度理解，就是把 $(-1, 0)$ 当做起点，且第一步只能往下走
