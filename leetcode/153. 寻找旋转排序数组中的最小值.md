```python
class Solution:
    def findMin(self, nums: List[int]) -> int:
        n = len(nums)
        left, right = 0, n - 1

        while left <= right:
            mid = (left + right) // 2
            if nums[mid] <= nums[-1]:
                right = mid - 1
            else:
                left = mid + 1
        
        return nums[left]
```

将二分结果与最后一个数 `nums[n - 1]` 比大小：
- 如果 `x > nums[n - 1]`，则 `nums` 一定被分成左右两个递增段，且 `x` 在第一段，最小值在第二段。最小值一定在 $x$ 的右边
- 如果 `x <= nums[n - 1]`，则 `x` 一定在第二段，最小值一定在 `x` 左边
