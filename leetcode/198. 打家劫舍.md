```python
class Solution:
    def rob(self, nums: List[int]) -> int:
        n = len(nums)
        @cache
        def dfs(i: int) -> int:
            if i < 0:
                return 0
            return max(dfs(i - 1), dfs(i - 2) + nums[i])
        return dfs(n - 1)
```
偷或不偷：从右往左（或从左往右）偷的过程中，偷 i 就不能偷 i - 1 只能去偷 i - 2，不偷 i 就能偷 i - 1
因此：
- 递归边界 `i < 0`（没有房子）
- 递归入口：`dfs(n - 1)` (从最后一个房子开始偷)
- 状态转移方程：`max(dfs(i - 1), dfs(i - 2) + nums[i])`

```python
class Solution:
    def rob(self, nums: List[int]) -> int:
        f = [0] * (len(nums) + 2)
        for i, x in enumerate(nums):
            f[i + 2] = max(f[i + 1], f[i] + x) # f[i + 2] 才是当前 f 数组对应位置
        return f[-1]
```
翻译成递推：如果直接把 `dfs(i)` 翻译成 `f[i]`，会访问 `f[-2]` 和 `f[-1]` 下标就**越界**了。解决办法：在 `f` 数组前面插入两个 0，把 f 数组整体往**右偏移 2 位**。偏移后，`dfs(i)` 翻译成 `f[i + 2]`
