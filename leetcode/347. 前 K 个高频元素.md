```python
class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        cnt = Counter(nums)
        max_count = max(cnt.values()) # {值: 次数}

        buckets = [[] for _ in range(max_count + 1)]
        for num, c in cnt.items():
            buckets[c].append(num)
        
        ans = []
        for bucket in reversed(buckets):
            ans += bucket
            if len(ans) == k:
                return ans
```

**桶排序：**
第一步：既然要有出现次数，先用 `Counter()` 统计每个元素的出现次数（ `{值: 次数}`）

第二步：把出现次数相同的元素，放在同一个桶 `bucket` 中。桶的大小取决于出现次数的最大值 `max_count`，确切大小是 `max_count + 1`。`buckets[c] = []` 表明：出现次数为 `c` 的元素存储在这个列表中。遍历 `Counter()` 用 `items()`，这样就是 `(key, value)`，也就是 `(值, 出现次数)`。遍历 `cnt` 分桶

第三步：倒序遍历 `buckets`加入答案，根据 `ans` 长度判断加入了出现次数第几大的元素。
