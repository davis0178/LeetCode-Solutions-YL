```python
class Solution:
    def partitionLabels(self, s: str) -> List[int]:
        last = {c: i for i, c in enumerate(s)}
        ans = []
        start = end = 0
        for i, c in enumerate(s):
            end = max(end, last[c])
            if end == i:
                ans.append(end - start + 1)
                start = i + 1
        return ans
```

“同一字母最多出现在一个片段中” -> 一个片段若要包含字母 a，那么所有的字母 a 都应该在这个片段中
所以遍历 `s` 时计算字母 `c` 在 `s` 中最后出现的下标 `last[c]`，初始化当前正在合并的区间左右端点 `start`, `end`。再次遍历 `s`，由于当前区间必须包含所有 `s[i]`，所以用 `last[s[i]]` 更新区间右端点 `end` 的最大值。
如果发现 `end = i`，则当前区间合并完毕，把区间长度 `end - start + 1` 加入答案。然后更新 `start = i + 1` 作为下一个区间的左端点
