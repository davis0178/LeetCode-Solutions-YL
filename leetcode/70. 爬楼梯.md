```python
class Solution:
    def climbStairs(self, n: int) -> int:
        @cache
        def dfs(i: int) -> int:
            if i <= 1:
                return 1
            return dfs(i - 1) + dfs(i - 2)
        return dfs(n)
```
**递归 + 记录返回值 = 记忆化搜索:**
将原问题变成和原问题相似的、规模更小的子问题：
- 如果最后一步爬了 `1` 个台阶，那么我们得先爬到 `i - 1`，要解决的问题缩小成：从 `0` 爬到 `i - 1` 有多少种不同的方法
- 如果最后一步爬了 `2` 个台阶，那么我们得先爬到 `i - 2`，要解决的问题缩小成：从 `0` 爬到 `i - 2` 有多少种不同的方法
因此可以用**递归**解决。由于这两种方法是互相独立的，所以根据加法原理，从 `0` 爬到 `i` 的方法数等于这两种方法数之和，即 $dfs(i)=dfs(i−1)+dfs(i−2)$
**递归边界**：$dfs(0) = 1$，$dfs(1)=1$（只有一种方法）
**递归入口**：$dfs(n)$
整个递归中有大量重复递归调用（先爬 `1` 个台阶再爬 `2` 个台阶和先爬 `2` 个台阶再爬 `1` 个台阶都相当于爬 `3` 个台阶），同样的入参无论计算多少次，算出来的结果都是一样的。因此可以使用**记忆化搜索**来优化（Python 直接用 `@cache` 装饰器）

```python
class Solution:
	def climbStairs(self, n: int) -> int:
		f = [0] * (n + 1)
		f[0] = f[1] = 1
		for i in range(2, n + 1):
			f[i] = f[i - 1] + f[i - 2]
		return f[n]
```
**1:1 翻译成递推：**
自底向上计算，`f[i]` 的定义和 `dfs(i)` 的定义是一样的，相应的**递推式**：$$
f[i] = f[i - 1] + f[i - 2]$$
初始值 `f[0] = 1`，`f[1] = 1`，答案为 `f[n]`
