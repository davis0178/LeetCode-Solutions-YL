```python
class Solution:
    def canJump(self, nums: List[int]) -> bool:
        right = 0
        for i, x in enumerate(nums):
            if i > right:
                return False
            right = max(right, i + x)
        return True
```

维护最右可达到的位置，初始值为 0
从左到右遍历 `nums`，如果当前 `i > right`，则跳不到 `i`，返回 False
否则，用 `i + x` 更新 `right` 的最大值。循环结束后能够返回 True
