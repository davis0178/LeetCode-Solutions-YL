```python
class Solution:
    def dailyTemperatures(self, temperatures: List[int]) -> List[int]:
        n = len(temperatures)
        ans = [0] * n
        st = []
        for i in range(n - 1, -1, -1):
            t = temperatures[i]
            while st and t >= temperatures[st[-1]]:
                st.pop()
            if st:
                ans[i] = st[-1] - i
            st.append(i)
        return ans
```

**单调栈：**
**从后往前**，当当前温度大于**等于**之前记录的温度，就一直删去之前记录的温度（等于也行，因为相当于找之后比当前高的温度，等于是不能更新答案的，也不能给再之前的日期一个更高的温度，所以还是爆掉 `st[-1]`）
如果最后还有记录的温度比当前温度大，当前答案就可以更新（而且就是离当前温度最近的更高温度）
记录当前温度
这些操作下来，栈中记录的是**下一个更大元素的候选项下标**（记录下标，可以得到更多信息）

```python
class Solution:
    def dailyTemperatures(self, temperatures: List[int]) -> List[int]:
        n = len(temperatures)
        ans = [0] * n
        st = []
        for i, t in enumerate(temperatures):
            while st and t > temperatures[st[-1]]:
                j = st.pop()
                ans[j] = i - j
            st.append(i)
        return ans
```

**从前往后**，当前温度在大于栈中记录温度时可以被用来更新之前的答案
更新完之前的答案后，再把当前温度加入栈中。
如此以来，栈中记录的是还没算出下一个更大元素的那些数的下标（to-do list）
